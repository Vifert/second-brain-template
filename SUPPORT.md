# Getting help

- **Setting up, or a question about how something works** — ask in
  [Discussions → Q&A](https://github.com/Vifert/second-brain-template/discussions/categories/q-a).
- **Something is broken** — open an [issue](https://github.com/Vifert/second-brain-template/issues/new/choose)
  with the bug form, including the output of `node tools/selftest.js` and
  `node tools/build-index.js`.
- **An idea to make the method better** — read [ROADMAP.md](ROADMAP.md), then
  open an Improvement Proposal.
- **A security problem** — see [SECURITY.md](SECURITY.md); never a public issue.

Questions about Obsidian itself or the Calendar, Iconize, Templater or
Excalidraw plugins belong with those projects.
