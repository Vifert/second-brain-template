# Defect Ledger

Every defect the vault has had, why it happened, and **what now stops it
recurring**. The procedure is in the manual every coding agent reads,
`AGENTS.md` § Defect Discipline: fix the instance, find the root cause, prevent
the class, record it here.

**Guard** says where the prevention lives:

- `selftest` / `build` / `audit` — a mechanical check. Its code in
  `tools/selftest.js`, `tools/build-index.js` + `tools/lib/`, or `tools/audit.js`
  cites the ID in a problem message or a test name — in code, not just a
  comment, because comments are stripped before the check (D39).
- `rule:<Section>` — a rule in that section of `AGENTS.md` (or of the
  Claude-only lines in `CLAUDE.md`) or of a `.claude/rules/` file.
- `hook` — a hook registered in `.claude/settings.json`, and generated into
  `.codex/hooks.json` for Codex (D91); its code in `tools/hooks/` or
  `tools/lib/hooks.js` cites the ID.
- `skill:<name>` — the procedure in `.claude/skills/<name>/SKILL.md`, a skill
  only the owner starts; the self-test checks the skill exists and its text
  cites the ID.

`node tools/selftest.js` verifies every kind of reference, so this ledger cannot
claim a guard that does not exist. **Append new rows; never renumber.**

**Where these rows come from.** D01–D79 were found and fixed in Vifert's own
vault, where this architecture was built between 9 and 23 September 2026. They
ship with every copy so a new vault starts with every guard already in place and
never pays for the same mistake twice. Third parties, employers, clients and
documents have been taken out of the rows; where a row says "Vifert", it means
the owner of that original vault. D80–D85 were found preparing this template
for release. D86–D88 are the original vault's D80–D82, ported: from D80 the two
ledgers number separately, so a ported row takes the next free ID here and
names the original's. D89 came from the template's own upkeep, and D90–D93 from making it run
under any coding agent. **This vault's own defects start at D200.**
*Latent* rows were caught before they shipped; *pre-empted* rows are guards
designed in alongside a new feature.
